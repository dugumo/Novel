# Novel 小说创作仓库

本仓库用于管理小说创作，采用「单一 dev 分支 + 文件夹区分作品」的组织方式。

## 分支规范
- `master`：默认主干，仅存放本 README 与仓库索引，不存放小说正文。
- `dev`：创作主分支，所有小说作品按文件夹区分，统一存放在此分支下。
  - 目的：让创作助手能随时通读所有作品正文，以便学习并保持统一文风。

## 目录规范
```
output/novel/
├── README.md          ← 仓库索引（master 与 dev 均保留）
├── 雾中来信/          ← 作品一（测试作，参考）
├── 平章/              ← 作品二（idea 创意归档版）
└── <后续作品名>/      ← 每新增一部小说，建一个同名文件夹
```
