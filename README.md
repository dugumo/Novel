# Novel 小说创作仓库

本仓库用于管理小说创作，采用「一本小说一个分支」的组织方式。

## 分支规范
- `master`：默认主干，仅存放本 README 与仓库索引，不存放小说正文。
- 每本小说：一个独立分支，分支名即小说名（如 `雾中来信`）。

## 提交规范
- 提交身份：刘伽椰 <18761691212@163.com>
- 提交信息：采用约定式提交（feat/docs/chore 等）。

## 推送（push）
- 默认不自动推送，需人工确认后执行。
- 远程仓库：git@github.com:dugumo/Novel.git
