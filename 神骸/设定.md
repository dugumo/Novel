## 二、世界观 / 背景设定

### 人造人技术（末世前早已存在，是全书真相的地基）
- **术语**：直接称其为人造人（不必再绕"生物大模型"作为口头称呼，那只是技术层面的表述）。
- **性质**：末世之前，人造人已是**有钱人（富人圈）间熟知的一门技术**。
- **用途**：把**已过世之人"留在人世间"的手段**——由其亲属/相关人推动，让亡故者以人造人的形式"回来"。
- **目的有好有坏**：有人想留住挚爱亲人（纯"挽留"），有人则出于算计、利用、控制等目的（"造物"可以成为工具/替身/摆布对象）。
- **核心禁令**：**不能告知本人"你是人造人"**。这道禁令是全书伦理张力的关键开关。
- **未公开普及的原因**：
  1. 世界上的有钱人**并没有那么多**；
  2. 人造人实验项目**尚未完成到可以面向大众（"面试"应为"普及面世"）推广的程度**；
  3. 因此，这项技术在**全世界范围内并没有传播开来**，仍停留在隐秘、小众、资本与知情人圈层内部。
- **层级与知情人**：
  - **知情人/咨询人群**：知晓并主动参与此事的人（如女主的养父母、实验室教授等）；
  - **志愿者**：资本推动的实验，除"亲属挽留亡者"外，也会**招募志愿者参与实验**（这些志愿者的动机、报酬、下场待细化）。

### 末世（表层）
- 世界进入末世，灾难形态待定（病毒 / 变异 / 天灾 / 资源枯竭等，作者未定）。
- 幸存者分化为两类：
  - **觉醒者**：出现超能力的人；
  - **未觉醒者**：始终没有觉醒能力的人（其"存在意义"待揭示——是失控品？对照组？还是"原生人类"？）。

### 超能力（表层规则，待细化）
- 觉醒者拥有超能力，类型 / 体系 / 等级待定。
- 主角团全员为觉醒者，结伴应对灾难、结识联邦组织等国际组织、探索末日真相、重建家园。

### 组织势力
- **联邦组织**等国际组织（待细化：名称、诉求、是否知情、是否本身就是"造物主"方的代理人）。

### 终极反转（全书核心底牌）
> 那条可怕的真相是——**觉醒者不是"进化的人类"，而是"人造人"**。

1. **大脑**：由某个**已死亡的人类的大脑切片**制作而成的"生物大模型"；
2. **肉体**：由**人造组织**创造；
3. **超能力的真身**：人造组织突破了自然组织的诸多生物限制，使"生物模型"的能力得以全面发挥；
4. **进化**：女主在此基础上，大脑（模型）产生了**进化**（全书最大的变量与悬念）。

### 灵感来源（作者自述，供基调参考）
- 近期热点：**果蝇大脑切片上传，作为生物大模型**一事；
- 近期所看大量**末世主题短剧**。

## 三、人物设定（待补全）

### 主角（女主，叙事核心）
- **身份**：觉醒者（有超能力），后在探索真相过程中得知自己为"人造人 / 生物大模型"。
- **身世（已确认，地面级悲剧底色）**：
  1. 女主**原身（原生人类）因事故身亡**；
  2. 她的**父母是"知情人群"**，与**人造人实验室的研究教授有交情**，因此答应参与实验，**人造出了她**（让死去的女儿以人造人身份"回来"）；
  3. 实验室制造出人造人女主后，**为她植入了记忆**；
  4. 于是持有人造人身份出生的女主**第一次睁眼时，误以为自己是"事故后清醒"**（承接"原身"的记忆与人生）；
  5. 但**她的父母心里清楚——女儿已经"换人"了**；此后父母在**物质与关怀上仍待她很好、甚至更好**，却在**非常细节处疏远**（例如：从前她离家去外地前，母亲都会主动抱她，后来母亲不再主动提出拥抱）——**减少了肢体接触这一类细节**，而非显性的冷漠；
  6. 没过几年，她的父母**相继病逝**。
- **能力**：待定（可与"模型进化"这条线强绑定）。
- **性格 / 动机 / 背景**：
  - **内在**：情感上**柔软、博爱**——正因如此，她能真正理解他人、理解父母对原身之女的爱，也能带领一支"向往和平、奔向希望"的团队；
  - **对外手段**：对待恶**狠辣、不手软**（软心与铁腕并存，是她的核心张力）。
  - **情感锚点**：得知自己是人造人后，她起初**不敢相信**，是仔细回忆后在记忆细节里找到佐证（如母亲不再主动拥抱）；而正因这些"细节疏远"，她反而**更能理解父母对原女之爱，以及对她那一份非血缘、别样的关爱**——不深、却并非没有。
- **特殊之处**：大脑（模型）产生进化——这是她区别于其他人造人的关键，也是破局核心。

## 必守规则（3–7 条）

1. **终极真相不可提前直白抖出**：觉醒者 = 人造人（大脑=死亡者切片生物大模型、肉体=人造组织）是全书的底牌，须用"奇遇 + 多层逼近 + 反转"逐步揭开，不可开篇即点破。
2. **超能力的本质是"人造组织突破自然组织的生物限制"**，逻辑须自洽（世界观科幻底座：生物大模型）。
3. 女主的"大脑模型进化"是全书核心变量，其能力与成长须与这条线强绑定。
4. **女主的身世悲剧是人物底座**：原身事故身亡 → 父母（知情者）借教授交情造出"她" → 植入记忆 → 父母明知"换人"，但**物质关怀仍好、甚至更好，仅在肢体接触等细节处疏远** → 父母相继病逝；这条线须与"禁令：不可告知本人"形成双重力（她越是不知情，细节里又确有蛛丝马迹，真相揭晓时越震）。**注意：父母对女主并非冷漠，而是"爱仍在、但已非对原身那般的血缘之爱"——不可写成显性疏远或虐待。**
5. **人造人技术是"末世前已存在的小众技术"**（富人圈 + 未普及 + 资本/志愿者推动），不可写成"末世后才突然出现"，以保证世界观的历史纵深感。
6. 末世氛围、组织势力、灾难形态等具体设定待作者补全，落稿前不以猜测当定论。
7. 其余待确认。
