# 《雾中来信》设定

> 测试稿（待确认）。可按需求增删小节；分章梗概以 `大纲.md` 为准。

## 一、基础信息

- 书名：雾中来信
- 题材/类型：都市悬疑
- 基调：冷峻、烧脑、带一点克制的温情
- 预计字数：短篇连载（测试用，先写两章）
- 一句话梗概（人物+冲突+悬念）：一名深陷职业倦怠的记者收到一封来自"十五年前已故挚友"的来信，为查证真相重返故乡雾镇，却发现收件人竟是他自己三年前就写好的遗书。
- 核心主题：真相与执念的代价；人如何在"放不下"与"活下去"之间做选择。
- 内容简介（可选）：记者林深在都市浮沉多年，早已习惯用麻木包裹过去。一封没有寄件人、字迹属于死去挚友的信，把他拽回被雾常年笼罩的小镇。越查，他越分不清：是挚友没死，还是连"写信的人是谁"都成了一个问题。

## 二、世界观 / 背景设定

### 时空与社会背景

- 时代：当代（近现代都市）。
- 地点：南方某江城梅州市，以及下辖山区雾镇。
- 故事时间跨度：约两周（第一章开始往回倒叙部分往事）。
- 主要场景：雾镇的旧报社、老街照相馆、一座常年起雾的废弃天文台、主角在城里的小公寓。

### 社会背景

- 主角是纸媒没落年代的都市记者，行业压力大、内容流量化。
- 雾镇曾是矿业小镇，矿山关停后人口大量外流，留下老人与重重山雾；镇上有旧报社分社、一间老照相馆，保存着许多未洗出的胶卷底片。

### 特殊规则（悬疑 / 刑侦向，本作偏私访不涉程序）

- 本作不走警方办案主流程，主角以记者身份私访调查，没有执法权。
- 关键悬念建立在"物证"上：信件、旧底片、录音带，均需能自洽解释，不可凭空出现超自然解释（除非后续设定推翻）。
- 雾是氛围与信息遮蔽的意象：雾镇常年起雾，许多关键线索发生在"看不清"的时刻，真相需要一层层散开。

## 三、人物设定

### 主角：林深

| 条目 | 说明 |
|------|------|
| 姓名 / 年龄 / 职业 | 林深 / 32 岁 / 都市网媒记者（前调查记者） |
| 外貌特征 | 瘦高，常年熬夜的眼下一片青黑；左手食指有一道旧疤（中学时替人挡玻璃割的）；习惯用右手拇指摩挲那封信的折痕 |
| 性格标签 | 表面冷淡疏离、用工作麻木自己、骨子里放不下真相 |
| 核心动机 | 想知道"来信的人到底是谁"，也想为十五年前的旧案讨一个答案 |
| 致命缺陷 | 执念太重，为了查真相不惜隐瞒、越界、把自己和身边人拖下水 |
| 背景故事 | 十五年前，挚友苏遥在雾镇失踪，警方判定"离家出走"，林深被迫接受；三年前他写下一封未寄出的遗书，把对苏遥的亏欠都写了进去。那封遗书本应锁在公寓抽屉里，如今却以苏遥的笔迹寄回了他自己。 |

### 重要角色：苏遥（失踪挚友 / 悬念核心）

| 条目 | 说明 |
|------|------|
| 姓名 / 年龄 | 苏遥 / 若在世应 32 岁，十五年前失踪于雾镇 |
| 身份 | 林深中学时代最好的朋友，天文迷，雾镇人 |
| 记忆点 | 字迹清瘦、右撇子但写信时习惯在句尾画一个不闭合的小圆圈 |
| 与主角关系 | 林深唯一的挚友，也是林深心里最大的亏欠（当年他没接苏遥最后一通电话） |
| 状态 | 官方结论"离家出走"，多年无音讯；本作悬念核心 |

### 反派 / 关键配角（预留）

- 老韩：雾镇照相馆老板，六十多岁，守着满屋底片，对当年的事讳莫如深，提供关键线索也藏着秘密。
- 苏遥的妹妹 苏念：比苏遥小五岁，在城里做程序员，脾气硬，对林深有隐约的怨。
- 未具名的"寄信人"：本作最大悬念，暂不揭底。

## 四、人物关系网

### 情感 / 情谊线

- 林深 ↔ 苏遥：挚友，也是林深的"执念"。当年那通没接的电话，是林深多年的心病。
- 林深 ↔ 苏念：旧识、若即若离，因苏遥的事彼此都放不下，却又互相刺探。

### 利益 / 对立

- 林深 ↔ 老韩：信息提供者与隐藏者，相互利用又相互防备。
- 林深 ↔ 寄信人：一场隔着十五年时间的博弈，谁在利用谁的愧疚与执念。

## 五、情节结构预想

### 主线任务

- 查清：这封"苏遥笔迹的信"到底是谁寄的，内容为何是林深三年前写的遗书，苏遥当年到底去了哪里。

### 分阶段（开端—发展—高潮—结局）

- 开端：林深收到"死去的挚友"的来信，信纸内容竟是自己三年前写下的遗书（第一章）。
- 发展：林深返回雾镇，走访照相馆老板老韩、妹妹苏念，线索指向被埋藏的旧案（第二章起）。
- 高潮：（后续章节预留）真相揭开，"谁在写信"与"当年发生了什么"同时反转。
- 结局：（后续章节预留）林深与自己的执念和解。

## 必守规则

1. 全作无超自然，所有悬念须可用现实逻辑解释。
2. 林深没有执法权，只以记者身份私访，不越界扮演警方。
3. 关键物证（信、底片、磁带）前后须自洽，不凭空升格。
4. "寄信人的身份"是全书核心钩子，前两章只埋线、不揭底。
5. 雾是气氛与遮蔽意象，不赋予实体能力。
6. 人物动机须有据：林深的执念、苏念的怨、老韩的隐瞒，各有来由。
